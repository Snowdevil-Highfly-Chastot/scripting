# 🛠️ DevScripts & Utilities

Welcome to my personal collection of automation scripts, development utilities, and workflow hacks. This repository serves as a centralized toolbox to streamline repetitive tasks, configure environments, and speed up daily development workflows.

---

## 🚀 What's Inside?

The repository is organized by language and use-case to keep things organized:

*   **`Bash/`**: Environment setup, git automation aliases, and system maintenance shortcuts.
*   **`Python/`**: Data scraping, file parsing, bulk renaming, and quick API testers.
*   **`Browser/`**: Scripts that can be ran in browser.

---

## 🛠️ Contributing & Customization

Since this is a living toolbox, I regularly add new scripts as manual pain points arise.

* Feel free to fork this repo and adapt the scripts to your own workflow.
* If you spot a bug or have an optimization for an existing script, pull requests are always welcome!
